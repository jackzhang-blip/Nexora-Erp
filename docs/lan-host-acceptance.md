# 局域网固定主机实机验收

此清单用于首版内部试用。请使用测试实例及测试数据，在 Windows x64 和 Apple 芯片 Mac 上安装各自生成的安装包，并记录系统版本、安装包提交号及结果。CI 和单机检查不能替代以下跨机结果。

## 连接组合

| 固定主机 | 客户端 | 预期结果 |
| --- | --- | --- |
| Windows x64 | Windows x64 | 发现或输入局域网地址，核对指纹后登录并读取库存 |
| Windows x64 | macOS Apple 芯片 | 同上 |
| macOS Apple 芯片 | Windows x64 | 同上 |
| macOS Apple 芯片 | macOS Apple 芯片 | 同上 |

每个组合都需确认：首次连接前只展示证书指纹，核对后才能保存信任；退出客户端重新打开可自动连接；更换主机证书后自动连接被阻止，界面要求再次核对。

## 主机生命周期

1. 在主机上创建测试实例，完成管理员初始化。记录服务状态、实例名称、端口和证书指纹，不记录密码。
2. 关闭桌面窗口并完全退出桌面应用。客户端仍能发现并访问服务，库存读写正常。
3. 重启主机，在**无人登录**时从另一台设备访问健康接口和已保存的连接；登录主机后确认服务状态仍为运行中。
4. 在主机设置中停止服务。客户端应显示断线，禁止新编辑提交；重新启动服务后自动恢复读取，必要时重新登录。
5. 断开主机网络再恢复，检查客户端的断线提示、发现结果和重连；测试网络变动时服务仍可手动通过地址连接。
6. 两台客户端同时登录，交替创建测试入库单并确认；检查库存流水、来源单据和最终数量一致。

## 升级与恢复

1. 在升级前记录测试库存和证书指纹，使用设置中的升级入口；确认升级前备份包含 `nexora.db`、`server.crt`、`server.key`，服务重新运行后数据与指纹不变。
2. 停止服务，将备份恢复到**新的**数据目录；按 [后端恢复说明](../backend/README.md#固定主机管理与升级) 指向该目录后启动，核对测试库存与原证书指纹。
3. 尝试把损坏或缺少证书的备份恢复到新目录；应明确报错，且不得留下可误用的部分实例。

只有上述全部组合和步骤有实机记录后，才将首版局域网交付标为已验收。签名、公证、自动更新及 Intel Mac 不在本轮验收范围。
